# Modelagem-Termica-e-Processamento-de-Sinal-de-Termopar-MI
Simulação da resposta térmica de um termopar industrial de isolação mineral (MI), com junção não aterrada, utilizando o método das diferenças finitas (FTCS) em Python. O projeto também implementa a Transformada Discreta de Fourier (DFT) e um filtro passa-baixas RC para atenuação de ruídos no sinal de temperatura simulado.
